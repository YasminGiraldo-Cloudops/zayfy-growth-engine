Pipeline de automatización — n8n + Claude API
Fase 1 · Monitoreo de Hashtags
Objetivo: Encontrar cuentas que pueden ser clientes de Zayfy.
Herramientas: n8n + Apify (scraping de IG/TikTok) o RapidAPI TikTok
Hashtags a monitorear:
#tiendaonline #vendoporinsta #tiktokshop #negocioscolombia #emprendimientocol #quieromitienda #venderportiktok #ecommercecol #negociodigital #páginavweb
Fase 2 · Calificación con IA
n8n llama a Claude API con el perfil de la cuenta.
Prompt base:
"Evalúa si esta cuenta de [Red] es un cliente potencial para una agencia tech que hace páginas web y automatizaciones para micronegocios latinoamericanos. Cuenta: [handle], Descripción: [bio], Seguidores: [n]. Responde JSON: { score: 1-10, razon: '...', nicho: '...' }"
Fase 3 · Generación de Outreach
Para leads con score ≥ 7, Claude genera un mensaje de DM personalizado.
n8n guarda en Google Sheets / Notion y te notifica por WhatsApp para aprobar antes de enviar.
Fase 4 · Publicación automática de contenido
n8n schedule (lun/mié/vie 9am) → Claude API genera post según calendario → Buffer/Later API → notifica para aprobar o publica directo.

Herramientas recomendadas:
• Publicación: Buffer API, Later, o Meta Content Publishing API
• n8n self-hosted (ya lo conoces) o n8n Cloud
• Apify para scraping de TikTok/IG (plan gratuito disponible)
• Claude API: Sonnet para generación, Haiku para calificación (costo bajo)
Costo estimado de IA por semana (40 leads + 3 posts): ~USD 0.50–1.50 con Haiku + Sonnet
